# Personal Portfolio Website

A high-end, studio-grade personal portfolio featuring a dark-mode, amber-accented aesthetic, official brand tool icons, and a dynamic project feed rendered via JSON.

## Tech Stack
* **Markup:** HTML5
* **Styling:** CSS3 (Flexbox, Grid, Custom Properties)
* **Logic:** Vanilla JavaScript (Dynamic JSON fetching)
* **Assets:** Devicon (Official Software Brand Icons)

## Features
* Responsive modern dark-theme design.
* Scalable project showcase managed via external `projects.json`.
* Interactive link arrows and clean card-grid layout.
